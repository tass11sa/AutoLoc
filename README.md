\# AutoLoc



Plateforme de gestion de location de véhicules multi-agences (étude de cas UP ASI, ESPRIT).



\## Objectifs du projet

\- Gérer le parc de véhicules de plusieurs agences de location

\- Gérer les clients, les réservations et les contrats de location

\- Exposer une API REST (Spring Boot) et la documenter avec Swagger

\- Mettre en place une chaîne d'outils Java/Spring complète et collaborative



\## Acteurs identifiés

\- \*\*Client\*\* : consulte les véhicules et réserve

\- \*\*Agent d'agence\*\* : gère les réservations et les retours de véhicules

\- \*\*Responsable d'agence\*\* : supervise son agence (véhicules, agents, statistiques)

\- \*\*Administrateur\*\* : gère les agences, les utilisateurs et la configuration globale



\## Environnement technique

Java 21, Spring Boot, Maven, MariaDB/MySQL (XAMPP), IntelliJ IDEA Ultimate, Postman, Git/GitHub.
